V112 dashboard reference-design update

Base: V111 Read Button Compact

Visual-only dashboard refresh based on the user-supplied reference image. The dashboard now uses a blue branded header, welcome/illustration banner, exactly three main feature cards (Students, Learning Material, Student Performance), a non-duplicating informational Recent Activity panel, and the lower motivational banner. There is no in-app bottom navigation/iPhone-style button bar.

Main dashboard feature cards are wired to dedicated hubs while reusing the existing student/material/performance functions. Existing test logic, attempts, scoring, history, reading, formula editing, pronunciation, back navigation, authentication, API routes, and database schema are otherwise unchanged.

This ZIP was not browser/Android/Render-tested; syntax and archive integrity were checked locally.
